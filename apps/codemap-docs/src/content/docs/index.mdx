`codemap-search` is a standalone Rust MCP stdio server and CLI for mapping repositories, running BM25 symbol searches, and reading live source files. It compiles Tree-sitter, Tantivy, and ripgrep into one binary, so it needs no external runtime, language server, or API key, and makes no network requests by default.

## Quick Start

Install from crates.io with Cargo to get started. For macOS/Linux `install.sh` and local source builds, see [Installation](/getting-started/installation/).

```sh
cargo install codemap-search
codemap-search --version
```

Register `codemap-search mcp` so your client launches it with the target project as its working directory:

```sh
# Claude Code (user scope across projects)
claude mcp add --scope user codemap-search -- codemap-search mcp

# Codex
codex mcp add codemap-search -- codemap-search mcp
```

For prebuilt binaries see [Installation](/getting-started/installation/). For Claude Code `project`/`local` scopes, Codex `config.toml`, `pi`, and `OpenCode`, see [MCP Client Setup](/getting-started/client-setup/).
