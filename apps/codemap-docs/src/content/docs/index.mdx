`codemap-search` maps repositories, searches symbols with BM25, and reads live source files over MCP stdio or the CLI. It compiles Tree-sitter, Tantivy, and ripgrep into one binary with no external runtime, language server, API key, or default network requests.

## Quick Start

Install from crates.io with Cargo, or see [Installation](/getting-started/installation/) for `install.sh`, Homebrew, WinGet, and local builds.

```sh
cargo install codemap-search
codemap-search --version
```

Register `codemap-search mcp` in your MCP client:

```sh
# Claude Code (user scope across projects)
claude mcp add --scope user codemap-search -- codemap-search mcp

# Codex
codex mcp add codemap-search -- codemap-search mcp
```

For Claude Code `project`/`local` scopes, Codex `config.toml`, `pi`, and `OpenCode`, see [MCP Client Setup](/getting-started/client-setup/).
