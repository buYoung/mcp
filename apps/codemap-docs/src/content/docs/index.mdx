`codemap-search` is a self-contained Rust MCP stdio server and CLI that maps a repository, searches extracted symbols, documentation, and literals with BM25, and confirms source with embedded `read`, `find`, and `grep`.

## Workflow: `initial_instructions` → `search` / `grep` → `read`

1. **`initial_instructions`**: Load navigation guidance and, in monorepos, list selectable `workspace_scope` targets and languages.
2. **`search` / `grep`**: Locate unknown implementations and concepts with ranked `search`, or enumerate exact identifiers and literals with `grep` (and `find` for file paths).
3. **`read`**: Inspect bounded live source windows (`offset`/`limit` or batched `ranges`) alongside enclosing declarations and caller context.
