## Files and precedence

Specify only the keys you want to override; settings merge per key as `repo > global > built-in default`. Open the [Playground](/playground/) in the top-right header to test settings live.

| Scope | `config.toml` (behavior) | `auth.toml` (API keys) |
| --- | --- | --- |
| Repo | `<repo>/.codemap/config.toml` | `<repo>/.codemap/auth.toml` |
| Global | `$CODEMAP_HOME/config.toml` (default `~/.codemap/config.toml`) | `$CODEMAP_HOME/auth.toml` (default `~/.codemap/auth.toml`) |

- `.gitignore`, global gitignore, and `.git/info/exclude` apply automatically. Add `.codemapignore` at the repository root to skip extra Git-tracked paths in indexing, `find`, and `grep`.
- Size keys accept positive integer bytes or quoted strings with `"b"`, `"kb"`, `"mb"`, or `"gb"` (powers of 1024, e.g., `"50mb"` = `52428800`).

```toml
# Minimal .codemap/config.toml example
[output.search]
max_bytes = "1mb"

[output.redact]
pii_entities = ["EMAIL_ADDRESS", "CREDIT_CARD"]

[filesystem_permissions]
find = "workspace"
grep = "workspace"
read = "workspace"
```

### Credential and PII redaction

<div class="cfg-scope-line"><code>[output.redact]</code></div>

| Key | Type | Allowed values | Default | Description |
| --- | --- | --- | --- | --- |
| `[output.redact].pii_entities` | string array | `[]` or built-in PII type array ([PII Redaction](/configuration/pii-redaction/)) | `[]` | Opt-in PII types to mask |
| `[output.redact].sensitive_fields` | string array | `[]` or field-name array | `[]` | Additional field names treated as secrets (case/separator normalized) |
| `[output.redact].rules` | inline-table array | `[]` or `{ id = "custom.*", pattern = "..." }` array | `[]` | Custom regex masking rules ([Credential redaction](#credential-redaction)) |
| `[output.redact].exceptions` | inline-table array | `[]` or `{ rule_id, value }` array | `[]` | Exact rule/value pairs exempt from masking ([Credential redaction](#credential-redaction)) |

<details class="cfg-details" id="credential-redaction">
<summary>Custom regex and exception rules (`[output.redact]`)</summary>

Rule IDs in `rules` must start with `custom.`. An optional `(?P<secret>...)` capture group masks only the captured portion. See [PII Redaction](/configuration/pii-redaction/) for all 90 built-in types and masking examples.

```toml
[output.redact]
pii_entities = ["EMAIL_ADDRESS", "CREDIT_CARD"]
sensitive_fields = ["internalCredential"]
rules = [{ id = "custom.acme", pattern = 'ACME_(?P<secret>[A-Z0-9]+)' }]
exceptions = [{ rule_id = "custom.acme", value = "ACME_EXAMPLE" }]
```

</details>
