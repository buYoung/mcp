## Files and precedence

Specify only the keys you want to override; settings merge per key as `repo > global > built-in default`. Open the [Configuration Playground](/configuration/playground/) to toggle settings and inspect live output changes across all 7 tools on `grafana/grafana`.

| Scope | `config.toml` | `auth.toml` (API keys) |
| --- | --- | --- |
| Repo | `<repo>/.codemap/config.toml` | `<repo>/.codemap/auth.toml` |
| Global | `$CODEMAP_HOME/config.toml` (default `~/.codemap/config.toml`) | `$CODEMAP_HOME/auth.toml` (default `~/.codemap/auth.toml`) |

`.gitignore`, global gitignore, and `.git/info/exclude` are respected automatically. Add `.codemapignore` at the repository root (gitignore syntax) to skip extra Git-tracked paths in indexing, `find`, and `grep`.

## Example `config.toml`

```toml
[output.search]
max_bytes = "1mb"

[output.redact]
pii_entities = ["EMAIL_ADDRESS", "CREDIT_CARD"]
sensitive_fields = ["internalCredential"]

[index]
mode = "auto" # "auto", "on", or "off" (restart required)

[index.exclude]
excluded_directories = [".idea", ".vscode", "node_modules", "target", "dist", "build", "vendor"]

[filesystem_permissions]
find = "workspace"
grep = "workspace"
read = "workspace"
```

## Output differences by option

On `grafana/grafana`, each example shows the **default output** first, followed by the output after changing the option. Try arbitrary combinations live in the [Configuration Playground](/configuration/playground/).

### 1. Call-relationship context (`[output.context].is_enabled` / `[output.navigation].is_enabled`)

Appends callers (`_callers_`) and callees (`_calls_`) under matched symbol declarations in `search`. Setting `[output.navigation].is_enabled = true` verifies imports and call structure and marks confirmed targets `precise`.

- **Default (`[output.context].is_enabled = true`, `[output.navigation].is_enabled = false`)**:
  ```markdown

  - `method DashboardServiceImpl.SaveDashboard` (L142-153)
    - _callers (approximate name scan):_
      - `pkg/api/dashboard.go:318` (`HTTPServer.PostDashboard`)
    - _calls (depth 1, approximate):_
      - `buildSaveDashboardCommand` — `pkg/services/dashboards/service/dashboard_service.go:96`
  ```
- **With structural verification (`[output.navigation].is_enabled = true`)**:
  ```markdown
  ## 1. pkg/services/dashboards/service/dashboard_service.go
  - `method DashboardServiceImpl.SaveDashboard` (L142-153)
    - _callers (tree-sitter precise; import/source resolution confirmed):_
      - `pkg/api/dashboard.go:318` (`HTTPServer.PostDashboard`, precise)
    - _calls (depth 1, tree-sitter precise):_
      - `DashboardServiceImpl.buildSaveDashboardCommand` — `pkg/services/dashboards/service/dashboard_service.go:96` (`precise`)
  ```

  ```markdown

  - `method DashboardServiceImpl.SaveDashboard` (L142-153)
  ```

## Key reference

| `[output].max_bytes` | size | unset, `>= 1` bytes, `"<int>b/kb/mb/gb"` | unset | Fallback MCP response ceiling when a tool-specific `max_bytes` is unset |

## Section details

### Global instructions

Detected client instruction file paths. Start a new agent session after changing `[global_instructions].enabled`:

| Client | Default file | Override env var |
| --- | --- | --- |
| Codex (`codex-mcp-client`) | `~/.codex/AGENTS.md` (`AGENTS.override.md` if non-empty) | `CODEX_HOME` |
| Claude Code (`claude-code`) | `~/.claude/CLAUDE.md` | `CLAUDE_CONFIG_DIR` |
| `pi` | `~/.pi/agent/AGENTS.md` | `PI_CODING_AGENT_DIR` |
| OpenCode (`opencode`) | `~/.config/opencode/AGENTS.md` | `OPENCODE_CONFIG_DIR` |

### Directory exclusions

Default `[index.exclude].excluded_directories` list: `[".idea", ".vscode", ".vs", "node_modules", ".yarn", "target", "dist", "build", "vendor"]`. Set `[]` to disable these defaults. VCS directories and `.codemap` are always excluded.

| Pattern | Matches |
| --- | --- |
| `build` or `**/build` | `build` at any depth |
| `./build` | Root `build` directory only |
| `apps/web/build` | That directory and everything under it |
| `apps/api/**/__pycache__` | `__pycache__` at any depth under `apps/api` |
| `apps/native/cmake-build-*` | Wildcard directory names under `apps/native` |

### Credential redaction

Rule IDs in `[output.redact].rules` must start with `custom.`. An optional `(?P<secret>...)` capture group masks only the captured match:

```toml
[output.redact]
pii_entities = ["EMAIL_ADDRESS", "CREDIT_CARD"]
sensitive_fields = ["internalCredential"]
rules = [{ id = "custom.acme", pattern = 'ACME_(?P<secret>[A-Z0-9]+)' }]
exceptions = [{ rule_id = "custom.acme", value = "ACME_EXAMPLE" }]
```

See [PII Redaction](/configuration/pii-redaction/) for all 90 built-in PII entity names and detailed masking examples.

### Macro expansion and event rules

Configure C/C++/assembly macro expansion (`clang` / `nasm`) and custom event-bus rules (`typescript`, `javascript`, `rust`) as follows:

```toml
[output.event_navigation]

use_builtin_rules = true
rules = [
  { id = "known-on", language = "typescript", module = "src/known.ts", symbol = "KnownBus", method = "on", role = "subscribe", event_arg = 0, handler_arg = 1, bus = "receiver" },
  { id = "known-emit", language = "typescript", module = "src/known.ts", symbol = "KnownBus", method = "emit", role = "publish", event_arg = 0, bus = "receiver" },
]
```

### Jev filter

Jev uses a decision model to omit irrelevant code blocks from `search`, `read`, and `grep` responses. Store the API key in `auth.toml` (or `TYPESAFE_API_KEY` / `OPENROUTER_API_KEY`) and enable `[output.jev]` in `config.toml`:

```toml
# .codemap/auth.toml
[jev]
api_key = "[REDACTED]"
[openrouter]
api_key = "[REDACTED]"
```

```toml
# .codemap/config.toml
[output.jev]
enabled = true
scope = ["search", "read", "grep"]
model = "jev-1.14.0" # or an OpenRouter ID below
```

#### OpenRouter decision models

| Maker | Model IDs |
| --- | --- |
| OpenAI | `openai/gpt-6-luna-decisions` |
