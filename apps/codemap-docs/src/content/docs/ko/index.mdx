`codemap-search`는 저장소 구조를 매핑하고 심볼과 문서를 BM25로 검색한 뒤 내장 `read`, `find`, `grep`으로 소스 원문을 확인하는 단일 Rust MCP stdio 서버이자 CLI입니다. Tree-sitter와 Tantivy, ripgrep을 바이너리 하나에 모두 담아 별도 런타임이나 언어 서버, API 키가 필요 없고 기본 설정에서는 네트워크 요청도 하지 않습니다.

## 빠른 시작

Cargo로 설치해 바로 시작하세요. macOS/Linux `install.sh`와 로컬 소스 빌드는 [설치](/ko/getting-started/installation/)에서 안내합니다.

```sh
cargo install codemap-search
codemap-search --version
```

탐색할 프로젝트 폴더를 작업 디렉터리로 두고 `codemap-search mcp`가 실행되도록 등록합니다.

```sh
# Claude Code (여러 프로젝트용 사용자 범위)
claude mcp add --scope user codemap-search -- codemap-search mcp

# Codex
codex mcp add codemap-search -- codemap-search mcp
```

사전 빌드 바이너리는 [설치](/ko/getting-started/installation/)에서, Claude Code의 `project`와 `local` 범위 및 Codex `config.toml`, `pi`, `OpenCode` 설정은 [MCP 클라이언트 등록](/ko/getting-started/client-setup/)에서 확인하세요.
