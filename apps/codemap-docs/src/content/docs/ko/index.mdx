`codemap-search`는 저장소를 색인해 추출한 심볼·문서·리터럴을 BM25로 검색하고 내장 `read`, `find`, `grep`으로 원문을 확인하는 단일 Rust 바이너리 MCP stdio 서버이자 CLI입니다.

## 탐색 흐름: `initial_instructions` → `search` / `grep` → `read`

1. **`initial_instructions`**: 탐색 안내를 불러오고, 모노레포에서는 선택 가능한 `workspace_scope` 범위와 언어를 확인합니다.
2. **`search` / `grep`**: 순위 기반 `search`로 낯선 구현과 개념을 찾고, `grep`으로 정확한 식별자와 리터럴을 전수 검색합니다(경로 탐색은 `find` 사용).
3. **`read`**: 필요한 줄 범위(`offset`/`limit` 또는 일괄 `ranges`)의 실제 파일 원문과 감싸는 선언·호출 관계 문맥을 읽습니다.
