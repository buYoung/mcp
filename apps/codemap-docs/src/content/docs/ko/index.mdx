`codemap-search`는 저장소 구조를 매핑하고 BM25로 심볼을 검색하며 소스 원문을 읽는 MCP stdio 서버이자 CLI입니다.

## 빠른 시작

운영체제에 맞는 명령으로 `codemap-search`를 설치하세요.

```sh
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/buYoung/mcp/main/apps/codemap-search/install.sh | sh

# Windows (CMD / PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://raw.githubusercontent.com/buYoung/mcp/main/apps/codemap-search/install.ps1 | iex"

# Cargo (crates.io)
cargo install codemap-search

codemap-search --version
```

사용하는 MCP 클라이언트에 `codemap-search mcp`를 등록하세요.

```sh
# Claude Code
claude mcp add --scope user codemap-search -- codemap-search mcp

# Codex
codex mcp add codemap-search -- codemap-search mcp
```
