## 파일 위치와 우선순위

바꿀 키만 적으면 되며, 키 단위로 `저장소 > 전역 > 기본값` 순으로 덮어씁니다. 실시간 설정 실험은 우측 상단 [플레이그라운드](/ko/playground/)에서 바로 해볼 수 있습니다.

| 범위 | `config.toml` (동작 설정) | `auth.toml` (API 키) |
| --- | --- | --- |
| 저장소 | `<repo>/.codemap/config.toml` | `<repo>/.codemap/auth.toml` |
| 전역 | `$CODEMAP_HOME/config.toml` (기본 `~/.codemap/config.toml`) | `$CODEMAP_HOME/auth.toml` (기본 `~/.codemap/auth.toml`) |

- `.gitignore`, 전역 gitignore, `.git/info/exclude`는 기본 적용됩니다. Git 추적 경로를 색인·`find`·`grep`에서 추가로 빼려면 저장소 루트에 `.codemapignore`를 두세요.
- 크기(`size`) 키에는 양의 정수 바이트 또는 `"b"`, `"kb"`, `"mb"`, `"gb"` 단위 문자열(1024 거듭제곱, 예: `"50mb"` = `52428800`)을 적습니다.

```toml
# .codemap/config.toml 최소 예시
[output.search]
max_bytes = "1mb"

[output.redact]
pii_entities = ["EMAIL_ADDRESS", "CREDIT_CARD"]

[filesystem_permissions]
find = "workspace"
grep = "workspace"
read = "workspace"
```

## 섹션별 설정 키

표 안의 배지(예: `▸ 디렉터리 제외 규칙`)를 누르면 페이지를 이동하지 않고 해당 행 바로 아래에 세부 규칙을 펼쳐 볼 수 있습니다.

### 출력 및 클라이언트 한도

<div class="cfg-scope-line"><code>[output]</code> <code>[output.client]</code></div>

| 키 | 자료형 | 설정 가능한 값 | 기본값 | 설명 |
| --- | --- | --- | --- | --- |
| `[output].is_redact_enabled` | bool | `true`, `false` | `true` | MCP 출력의 인증정보 및 선택 PII 마스킹 |
| `[output].max_bytes` | 크기 | 미지정, `>= 1` 바이트, `"<정수>b/kb/mb/gb"` | 미지정 | 도구별 `max_bytes`가 없을 때 적용할 공통 응답 상한 |
| `[output.client].claude_max_result_chars` | 정수(문자) | `1`–`500000` | `100000` | Claude Code 전달 한도(변경 후 MCP 재연결) |
| `[output.client].codex_output_token_limit` | 정수(토큰) | `>= 1` | `100000` | Codex 출력 토큰 한도(`codemap-search codex-config` 출력을 `~/.codex/config.toml`에 반영) |
| `[output.client].pi_max_bytes` | 크기 | `>= 1` 바이트, `"<정수>b/kb/mb/gb"` | `100000` | `pi`(`@buyong/pi-mcp-adapter`) 전달 한도(변경 후 MCP 재연결) |
| `[output.client].opencode_max_bytes` | 크기 | `>= 1` 바이트, `"<정수>b/kb/mb/gb"` | `100000` | OpenCode 전달 한도(`opencode.json`의 `tool_output.max_bytes`, 기본 `51200`과 일치 권장) |

[output.context.exclude.test_decorators]

### 인증정보·PII 마스킹

<div class="cfg-scope-line"><code>[output.redact]</code></div>

| 키 | 자료형 | 설정 가능한 값 | 기본값 | 설명 |
| --- | --- | --- | --- | --- |
| `[output.redact].pii_entities` | 문자열 배열 | `[]` 또는 내장 PII 유형 배열 ([PII 마스킹](/ko/configuration/pii-redaction/)) | `[]` | 마스킹할 PII 유형 목록 |
| `[output.redact].sensitive_fields` | 문자열 배열 | `[]` 또는 필드명 배열 | `[]` | 비밀값으로 처리할 추가 필드명(대소문자·구분자 정규화) |
| `[output.redact].rules` | 인라인 테이블 배열 | `[]` 또는 `{ id = "custom.*", pattern = "..." }` 배열 | `[]` | 사용자 정규식 마스킹 규칙 ([민감값 마스킹](#민감값-마스킹)) |
| `[output.redact].exceptions` | 인라인 테이블 배열 | `[]` 또는 `{ rule_id, value }` 배열 | `[]` | 마스킹에서 제외할 규칙·값 쌍 ([민감값 마스킹](#민감값-마스킹)) |

<details class="cfg-details" id="민감값-마스킹">
<summary>사용자 정규식·예외 규칙 예시 (`[output.redact]`)</summary>

`rules`의 `id`는 `custom.`으로 시작해야 하며, 정규식에 `(?P<secret>...)` 캡처 그룹을 넣으면 해당 부분만 마스킹합니다. 전체 90종 목록과 출력 예시는 [PII 마스킹](/ko/configuration/pii-redaction/)을 참고하세요.

```toml
[output.redact]
pii_entities = ["EMAIL_ADDRESS", "CREDIT_CARD"]
sensitive_fields = ["internalCredential"]
rules = [{ id = "custom.acme", pattern = 'ACME_(?P<secret>[A-Z0-9]+)' }]
exceptions = [{ rule_id = "custom.acme", value = "ACME_EXAMPLE" }]
```

</details>
