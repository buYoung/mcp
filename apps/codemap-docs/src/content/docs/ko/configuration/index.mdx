## 설정 파일과 우선순위

바꿀 키만 적으면 되며, 키 단위로 `저장소 > 전역 > 기본값` 순으로 적용됩니다. 설정 조합에 따라 `grafana/grafana`에서 7개 도구 출력이 어떻게 달라지는지 바로 시험하려면 [설정 플레이그라운드](/ko/configuration/playground/)를 열어보세요.

| 범위 | `config.toml` | `auth.toml` (API 키) |
| --- | --- | --- |
| 저장소 | `<repo>/.codemap/config.toml` | `<repo>/.codemap/auth.toml` |
| 전역 | `$CODEMAP_HOME/config.toml` (기본 `~/.codemap/config.toml`) | `$CODEMAP_HOME/auth.toml` (기본 `~/.codemap/auth.toml`) |

`.gitignore`, 전역 gitignore, `.git/info/exclude`는 기본으로 적용됩니다. Git에서 추적하는 경로를 색인, `find`, `grep`에서 추가로 빼려면 저장소 루트에 `.codemapignore`(gitignore 문법)를 두세요.

## `config.toml` 예시

```toml
[output.search]
max_bytes = "1mb"

[output.redact]
pii_entities = ["EMAIL_ADDRESS", "CREDIT_CARD"]
sensitive_fields = ["internalCredential"]

[index]
mode = "auto" # "auto", "on", "off" (변경 후 재시작 필요)

[index.exclude]
excluded_directories = [".idea", ".vscode", "node_modules", "target", "dist", "build", "vendor"]

[filesystem_permissions]
find = "workspace"
grep = "workspace"
read = "workspace"
```

## 설정 옵션에 따른 출력 차이

`grafana/grafana` 기준으로 모든 비교는 **기본값 출력**을 먼저 보여준 뒤 옵션을 바꿨을 때의 출력을 이어서 보여줍니다. 실시간 조합 비교는 [설정 플레이그라운드](/ko/configuration/playground/)에서 확인할 수 있습니다.

## 설정 키

바이트 크기 키에는 양의 정수 바이트 또는 `b`, `kb`, `mb`, `gb` 접미사가 붙은 문자열(1024 거듭제곱 기준, 예: `"50mb"` = `52428800`)을 적습니다. 표 안의 파란 배지(예: `▸ 디렉터리 제외 규칙`)를 누르면 페이지를 이동하지 않고 바로 아래에 상세 규칙을 펼쳐 볼 수 있습니다.

| 키 | 자료형 | 설정 가능한 값 | 기본값 | 설명 |
| --- | --- | --- | --- | --- |
| `[global_instructions].enabled` | bool | `true`, `false` | `false` | 클라이언트 전역 지침 파일에 탐색 안내 한 줄 자동 관리([전역 지침](#전역-지침), 전역 설정 전용) |
| `[output].is_redact_enabled` | bool | `true`, `false` | `true` | MCP 출력의 인증정보 및 선택 PII 마스킹 |
| `[output].max_bytes` | 크기 | 미지정, `>= 1` 바이트, `"<정수>b/kb/mb/gb"` | 미지정 | 도구별 `max_bytes`가 없을 때 적용할 공통 응답 상한 |
| `[output.client].claude_max_result_chars` | 정수(문자) | `1`–`500000` | `100000` | Claude Code 전달 한도(변경 후 MCP 재연결) |
| `[output.client].codex_output_token_limit` | 정수(토큰) | `>= 1` | `100000` | Codex 출력 토큰 한도(`codemap-search codex-config` 출력을 `~/.codex/config.toml`에 반영) |
| `[output.client].pi_max_bytes` | 크기 | `>= 1` 바이트, `"<정수>b/kb/mb/gb"` | `100000` | `pi`(`@buyong/pi-mcp-adapter`) 전달 한도(변경 후 MCP 재연결) |
| `[output.client].opencode_max_bytes` | 크기 | `>= 1` 바이트, `"<정수>b/kb/mb/gb"` | `100000` | OpenCode 전달 한도(`opencode.json`의 `tool_output.max_bytes`, 기본 `51200`과 일치 권장) |
| `[output.search].detail_file_limit` | 정수 | `>= 1` | `24` | 상세 발췌를 표시할 상위 파일 수 |
| `[output.search].overview_file_limit` | 정수 | `>= 1` | `80` | 간략 순위 목록에 표시할 최대 파일 수 |
| `[output.search].snippet_max_lines` | 정수 | `>= 1` | `500` | `search`에서 심볼당 최대 발췌 줄 수 |
| `[output.search].symbol_limit` | 정수 | `>= 1` | `100` | `search`에서 파일당 표시할 최대 심볼 수 |
| `[output.search].max_bytes` | 크기 | `>= 1` 바이트, `"<정수>b/kb/mb/gb"` | `"1mb"` (`1048576`) | `search` 1회 응답 크기 상한 |
| `[output.search].literal_max_chars` | 정수(문자) | `>= 1` | `1200` | 일치한 문자열 리터럴의 최대 표시 길이 |
| `[output.search].literal_limit` | 정수 | `>= 1` | `60` | `search`에서 파일당 최대 리터럴 표시 수 |
| `[output.search].anchor_snippet_limit` | 정수 | `>= 1` | `20` | 파일당 전체 발췌 최대 심볼 수(나머지는 선언부만 표시) |
| `[output.read].max_bytes` | 크기 | `>= 1` 바이트, `"<정수>b/kb/mb/gb"` | `"5mb"` (`5242880`) | `read` 및 함수 확장 `grep`의 출력 크기 상한 |
| `[output.read].is_outside_callers_enabled` | bool | `true`, `false` | `true` | `read view="source"` 끝에 범위 밖 호출자·import 파일 표시 |
| `[output.grep].max_columns` | 정수 | `0` (제한 없음) 또는 `>= 1` | `0` | 본문 모드 `grep`의 줄 길이 상한 |
| `[output.grep].max_bytes` | 크기 | 미지정, `>= 1` 바이트, `"<정수>b/kb/mb/gb"` | `[output].max_bytes` | `grep` 응답 크기 상한 |
| `[output.context].is_enabled` | bool | `true`, `false` | `true` | `search`에서 `caller_context` 생략 시 기본 호출 관계 표시 여부 |
| `[output.context].caller_limit` | 정수 | `>= 1` | `1000` | 심볼당 최대 호출자·참조 표시 수 |
| `[output.context].callee_limit` | 정수 | `>= 1` | `1000` | 심볼당 최대 호출 대상 표시 수 |
| `[output.context].max_bytes` | 크기 | `>= 1` 바이트, `"<정수>b/kb/mb/gb"` | `"128kb"` (`131072`) | `[output.search].max_bytes` 안의 호출 관계 표시 예산 |

| `[output.navigation].is_enabled` | bool | `true`, `false` | `false` | 호출 위치를 구조적으로 확인해 확정 대상을 `precise`로 표시 |

| `[output.redact].pii_entities` | 문자열 배열 | `[]` 또는 내장 PII 유형 배열 ([PII 마스킹](/ko/configuration/pii-redaction/)) | `[]` | 마스킹할 PII 유형 목록 |
| `[output.redact].sensitive_fields` | 문자열 배열 | `[]` 또는 필드명 배열 | `[]` | 비밀값으로 처리할 추가 필드명(대소문자·구분자 정규화) |
| `[output.redact].rules` | 인라인 테이블 배열 | `[]` 또는 `{ id = "custom.*", pattern = "..." }` 배열 | `[]` | 사용자 정규식 마스킹 규칙 ([민감값 마스킹](#민감값-마스킹)) |

## 주요 설정 상세

### 전역 지침

감지된 클라이언트의 전역 지침 파일 경로입니다. `[global_instructions].enabled`를 바꾼 뒤에는 새 에이전트 세션을 여세요.

| 클라이언트 | 기본 파일 | 경로 변경 환경 변수 |
| --- | --- | --- |
| Codex (`codex-mcp-client`) | `~/.codex/AGENTS.md` (비어 있지 않은 `AGENTS.override.md` 우선) | `CODEX_HOME` |
| Claude Code (`claude-code`) | `~/.claude/CLAUDE.md` | `CLAUDE_CONFIG_DIR` |
| `pi` | `~/.pi/agent/AGENTS.md` | `PI_CODING_AGENT_DIR` |
| OpenCode (`opencode`) | `~/.config/opencode/AGENTS.md` | `OPENCODE_CONFIG_DIR` |

### 디렉터리 제외 규칙

`[index.exclude].excluded_directories` 기본 목록은 `[".idea", ".vscode", ".vs", "node_modules", ".yarn", "target", "dist", "build", "vendor"]`입니다. 기본 제외를 모두 끄려면 `[]`로 설정하세요. VCS 폴더와 `.codemap`은 설정과 관계없이 항상 제외됩니다.

| 패턴 | 일치 범위 |
| --- | --- |
| `build` 또는 `**/build` | 모든 깊이의 `build` |
| `./build` | 저장소 루트의 `build`만 |
| `apps/web/build` | 해당 디렉터리와 하위 전체 |
| `apps/api/**/__pycache__` | `apps/api` 아래 모든 깊이의 `__pycache__` |
| `apps/native/cmake-build-*` | `apps/native` 아래 와일드카드 디렉터리 |

### 민감값 마스킹

`[output.redact].rules`의 규칙 `id`는 `custom.`으로 시작해야 합니다. 정규식에 `(?P<secret>...)` 캡처 그룹을 쓰면 해당 부분만 마스킹합니다.

```toml
[output.redact]
pii_entities = ["EMAIL_ADDRESS", "CREDIT_CARD"]
sensitive_fields = ["internalCredential"]
rules = [{ id = "custom.acme", pattern = 'ACME_(?P<secret>[A-Z0-9]+)' }]
exceptions = [{ rule_id = "custom.acme", value = "ACME_EXAMPLE" }]
```

내장 PII 유형 90종 목록과 상세 마스킹 예시는 [PII 마스킹](/ko/configuration/pii-redaction/)을 참고하세요.

### 매크로 확장과 이벤트 규칙

C/C++/어셈블리 매크로 전처리(`clang` / `nasm`)와 사용자 이벤트 버스 규칙(`typescript`, `javascript`, `rust`) 설정 예시입니다.

```toml
[output.macro_expansion]
is_enabled = true
compilation_database = "build/compile_commands.json"
clang_path = "clang"
nasm_path = "nasm"

nasm_flags = ["-Iinclude/", "-felf64"]

max_output_bytes = "8mb"

[output.event_navigation]
is_enabled = true
use_builtin_rules = true
rules = [
  { id = "known-on", language = "typescript", module = "src/known.ts", symbol = "KnownBus", method = "on", role = "subscribe", event_arg = 0, handler_arg = 1, bus = "receiver" },
  { id = "known-emit", language = "typescript", module = "src/known.ts", symbol = "KnownBus", method = "emit", role = "publish", event_arg = 0, bus = "receiver" },
]
```

### Jev 필터

Jev는 판정 모델로 `search`, `read`, `grep` 결과에서 작업과 무관한 코드 블록을 생략합니다. `auth.toml`(또는 `TYPESAFE_API_KEY` / `OPENROUTER_API_KEY` 환경 변수)에 API 키를 넣고 `config.toml`에서 `[output.jev]`를 켜세요.

```toml
# .codemap/auth.toml
[jev]
api_key = "[REDACTED]"
[openrouter]
api_key = "[REDACTED]"
```

```toml
# .codemap/config.toml
[output.jev]
enabled = true
scope = ["search", "read", "grep"]
model = "jev-1.14.0" # 또는 아래 OpenRouter 모델 ID
```
