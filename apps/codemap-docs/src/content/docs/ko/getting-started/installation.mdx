운영체제에 맞는 사전 빌드 바이너리를 설치하거나 Cargo로 소스에서 직접 빌드하세요.

## 설치 채널

| 운영체제 | 소스 빌드 | 사전 빌드 설치 |
|---|---|---|
| Linux | Cargo (`crates.io` 또는 로컬 소스) | `install.sh` 또는 GitHub 릴리스 압축 파일 |
| macOS | Cargo (`crates.io` 또는 로컬 소스) | `install.sh`, Homebrew 또는 GitHub 릴리스 압축 파일 |
| Windows | Cargo (`crates.io` 또는 로컬 소스) | WinGet 또는 GitHub 릴리스 압축 파일 |

## 설치

<Tabs>
    <TabItem label="설치 스크립트 (macOS / Linux)">
        OS와 아키텍처에 맞는 바이너리를 내려받아 `.sha256` 체크섬을 검증한 뒤 기본 경로 `~/.local/bin`에 설치합니다. POSIX 셸, `curl` 또는 `wget`, `tar`, `sha256sum` 또는 `shasum`이 필요합니다.

        ```sh
        curl -fsSL https://raw.githubusercontent.com/buYoung/mcp/main/apps/codemap-search/install.sh | sh
        ```

        설치 폴더를 바꾸려면 쓰기 권한이 있는 경로를 `INSTALL_DIR`에 지정하세요(기본 사용자 경로는 `sudo` 불필요). 특정 릴리스 태그(예: `codemap-v0.1.6`)를 고정하려면 `--version`을 넘깁니다.

        ```sh
        curl -fsSL https://raw.githubusercontent.com/buYoung/mcp/main/apps/codemap-search/install.sh | INSTALL_DIR=/usr/local/bin sh
        curl -fsSL https://raw.githubusercontent.com/buYoung/mcp/main/apps/codemap-search/install.sh | sh -s -- --version codemap-v0.1.6
        ```

        | 옵션 | 의미 |
        |---|---|
        | `INSTALL_DIR` | 설치 디렉터리(기본값: `~/.local/bin`) |
        | `--version` / `CODEMAP_VERSION` | 정확한 릴리스 태그. `--version`이 우선 |
        | `CODEMAP_LINUX_LIBC` | 기본값 `musl`. Linux x86_64에서만 `gnu` 선택 가능 |
        | `--print-target` | 다운로드 없이 대상, URL, 설치 경로만 출력 |

        정적 `musl` 빌드는 `glibc` 의존성이 없습니다. 지원 대상은 [릴리스 압축 파일 이름](#릴리스-압축-파일-이름)을 참고하세요.
    </TabItem>
    <TabItem label="Cargo (crates.io 및 소스 빌드)">
        Rust와 C 컴파일러 도구 모음이 필요합니다.

        ```sh
        cargo install codemap-search
        ```

        [crates.io](https://crates.io/crates/codemap-search)의 특정 버전을 지정하려면 `--version`을 붙이세요.

        로컬 체크아웃에서 직접 빌드하려면 저장소 루트에서 실행하세요.

        ```sh
        cargo install --path apps/codemap-search
        # 설치 없이 빌드만 할 때(출력: apps/codemap-search/target/release/codemap-search):
        cargo build --release --manifest-path apps/codemap-search/Cargo.toml
        ```
    </TabItem>
    <TabItem label="Homebrew (macOS)">
        Apple Silicon과 Intel Mac용 사전 빌드 바이너리를 설치합니다([Homebrew 포뮬러](https://formulae.brew.sh/formula/codemap-search)).

        ```sh
        brew install codemap-search
        ```

        새 릴리스가 아직 Homebrew에 반영되지 않았다면 `install.sh`, `cargo install`, 또는 [GitHub Releases](https://github.com/buYoung/mcp/releases)의 macOS 압축 파일을 사용하세요.
    </TabItem>
    <TabItem label="Windows (WinGet 및 GitHub 릴리스 압축 파일)">
        WinGet([패키지 매니페스트](https://github.com/microsoft/winget-pkgs/tree/master/manifests/c/com/livteam/codemap-search))으로 설치합니다.

        ```powershell
        winget install com.livteam.codemap-search
        ```

        수동 설치 시에는 [GitHub Releases](https://github.com/buYoung/mcp/releases)에서 Windows `.zip` 파일과 `.sha256` 파일을 내려받아 체크섬을 검증한 뒤 `codemap-search.exe`를 `PATH` 폴더에 넣으세요([릴리스 압축 파일 이름](#릴리스-압축-파일-이름) 참고).
    </TabItem>
</Tabs>

## 설치 확인과 `PATH`

`codemap-search --version`으로 설치를 확인한 뒤 [MCP 클라이언트 등록](/ko/getting-started/client-setup/)으로 이동하세요.

터미널이나 MCP 클라이언트가 `codemap-search`를 찾지 못하면 아래 설치 경로가 `PATH`에 포함되었는지 확인하세요(GUI 클라이언트는 `~/.zshrc`나 `~/.bashrc`를 읽지 않을 수 있습니다).

- **`install.sh`**: `~/.local/bin` (기본 `INSTALL_DIR`)
- **Cargo**: `~/.cargo/bin`
- **Homebrew**: Homebrew의 `bin` 디렉터리
- **Windows**: WinGet 별칭 반영을 위해 새 터미널을 열거나, `codemap-search.exe`가 있는 폴더 추가

## 릴리스 압축 파일 이름

사전 빌드 파일과 대응하는 `.sha256` 파일은 [GitHub Releases](https://github.com/buYoung/mcp/releases)에 게시됩니다.

| 운영체제 | 아키텍처 | 설치 파일 |
|---|---|---|
| Linux | x86_64, 기본 `musl` | `codemap-search-x86_64-unknown-linux-musl.tar.gz` |
| Linux | x86_64, `gnu` | `codemap-search-x86_64-unknown-linux-gnu.tar.gz` |
| Linux | arm64, `musl` 전용 | `codemap-search-aarch64-unknown-linux-musl.tar.gz` |
| macOS | Apple Silicon | `codemap-search-aarch64-apple-darwin.tar.gz` |
| macOS | Intel | `codemap-search-x86_64-apple-darwin.tar.gz` |
| Windows | x86_64 | `codemap-search-x86_64-pc-windows-msvc.zip` |
| Windows | arm64 | `codemap-search-aarch64-pc-windows-msvc.zip` |

## 문제 해결

- **다운로드 오류**: 선택한 릴리스 태그에 압축 파일과 `.sha256` 파일이 모두 있는지 [GitHub Releases](https://github.com/buYoung/mcp/releases)에서 확인하세요. 파일이 없으면 `install.sh`는 중단됩니다.
- **체크섬 불일치**: `install.sh`는 디렉터리를 만들거나 압축을 풀기 전에 중단합니다. 검증을 건너뛰지 말고 파일을 다시 받아 `.sha256` 값과 대조하세요.
- **쓰기 오류**: 쓰기 권한이 있는 폴더를 `INSTALL_DIR`로 지정하세요.
- **Cargo 빌드 오류**: [crates.io](https://crates.io/crates/codemap-search)에서 버전 존재 여부를 확인하고 `rustc`, `cargo`, C 컴파일러·링커 설치 상태를 점검하세요.
