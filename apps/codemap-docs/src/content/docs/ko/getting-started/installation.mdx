Cargo로 소스에서 직접 빌드하거나 운영체제에 맞는 사전 빌드 바이너리를 설치할 수 있습니다. `codemap-search`는 Tree-sitter 문법, Tantivy, ripgrep 라이브러리를 단일 Rust 바이너리에 담아 별도 `rg`나 언어 서버, 외부 런타임, API 키 없이 바로 동작하며 기본 설정에서는 네트워크 요청을 보내지 않습니다.

설치가 끝나면 `codemap-search --version`으로 동작을 확인한 뒤 [MCP 클라이언트 등록](/ko/getting-started/client-setup/)으로 넘어가세요.

## 설치 채널

| 운영체제 | 소스 빌드 | 사전 빌드 설치 |
|---|---|---|
| Linux | Cargo (`crates.io` 또는 로컬 소스) | 설치 스크립트 (`install.sh`) 또는 GitHub 릴리스 압축 파일 |
| macOS | Cargo (`crates.io` 또는 로컬 소스) | 설치 스크립트 (`install.sh`), Homebrew 또는 GitHub 릴리스 압축 파일 |
| Windows | Cargo (`crates.io` 또는 로컬 소스) | WinGet 또는 압축 파일 수동 설치 |

Cargo 빌드는 Rust와 C 컴파일러 도구 모음이 필요합니다. macOS/Linux 설치 스크립트는 표준 POSIX 도구, `curl` 또는 `wget`, `tar`, `sha256sum` 또는 `shasum`만 있으면 되며 기본으로 `~/.local/bin`에 설치합니다. Homebrew와 WinGet은 자체 경로에 설치합니다.

## 설치

<Tabs>
    <TabItem label="설치 스크립트 (macOS / Linux)">
        macOS와 Linux에서 OS와 아키텍처에 맞는 사전 빌드 바이너리를 받고 `.sha256` 체크섬을 검증한 뒤 기본으로 `~/.local/bin`에 설치합니다. Windows는 **Windows (WinGet 및 압축 파일)** 탭을 참고하세요.

        **사전 요구 사항:** POSIX 셸, 표준 시스템 도구, `curl` 또는 `wget`, `tar`, `sha256sum` 또는 `shasum`이 필요합니다.

        ```sh
        curl -fsSL https://raw.githubusercontent.com/buYoung/mcp/main/apps/codemap-search/install.sh | sh
        ```

        설치 후 `codemap-search --version`을 실행해 확인하세요. 명령을 찾지 못하면 스크립트가 출력한 `export PATH` 줄을 `~/.zshrc`나 `~/.bashrc`에 추가해 `~/.local/bin`을 `PATH`에 등록합니다.

        설치하려는 릴리스 태그에 압축 파일과 `.sha256` 파일이 모두 올라와 있는지 [GitHub Releases](https://github.com/buYoung/mcp/releases)에서 확인하세요.

        **설치 경로와 버전 지정**

        다른 폴더에 설치하려면 `INSTALL_DIR`을 넘깁니다. 쓰기 권한이 있는 폴더여야 하며 기본 사용자 경로는 `sudo` 없이 설치됩니다.

        ```sh
        curl -fsSL https://raw.githubusercontent.com/buYoung/mcp/main/apps/codemap-search/install.sh | INSTALL_DIR=/usr/local/bin sh
        ```

        특정 릴리스 버전을 고정하려면 `--version`으로 태그를 지정하세요(`codemap-v0.1.6`은 예시 태그이므로 실제 파일이 있는 태그를 넣으세요).

        ```sh
        curl -fsSL https://raw.githubusercontent.com/buYoung/mcp/main/apps/codemap-search/install.sh | sh -s -- --version codemap-v0.1.6
        ```

        | 옵션 | 의미 |
        |---|---|
        | `INSTALL_DIR` | 설치 디렉터리. 기본값 `$HOME/.local/bin` |
        | `--version` / `CODEMAP_VERSION` | 정확한 릴리스 태그. `--version`이 우선 |
        | `CODEMAP_LINUX_LIBC` | 기본값 `musl`. Linux x86_64에서만 `gnu` 선택 가능 |
        | `--print-target` | 다운로드 없이 대상, 다운로드 URL, 설치 경로만 출력 |

        태그를 생략하면 `releases/latest/download/<asset>`을 조회합니다. 모노레포의 최신 릴리스가 다른 제품 버전일 수 있으므로 재현 가능한 설치를 원하면 태그를 명시하세요. 설치용 환경 변수는 실행 중인 MCP 서버를 설정하지 않습니다.

        **지원 환경**

        | 운영체제 | 아키텍처 | 설치 파일 |
        |---|---|---|
        | macOS | arm64 / aarch64 | `codemap-search-aarch64-apple-darwin.tar.gz` |
        | macOS | x86_64 / amd64 | `codemap-search-x86_64-apple-darwin.tar.gz` |
        | Linux | x86_64 / amd64, 기본 musl | `codemap-search-x86_64-unknown-linux-musl.tar.gz` |
        | Linux | x86_64 / amd64, `CODEMAP_LINUX_LIBC=gnu` | `codemap-search-x86_64-unknown-linux-gnu.tar.gz` |
        | Linux | arm64 / aarch64, musl만 | `codemap-search-aarch64-unknown-linux-musl.tar.gz` |

        Linux는 `glibc` 의존성이 없는 `musl` 빌드가 기본입니다. x86_64 GNU 빌드가 필요하면 `INSTALL_DIR`과 같은 방식으로 `sh`에 `CODEMAP_LINUX_LIBC=gnu`를 전달하세요. Linux arm64는 `musl`만 지원합니다.
    </TabItem>
    <TabItem label="Cargo (crates.io 및 소스 빌드)">
        Rust/Cargo와 내장 파서 컴파일용 C 도구 모음으로 `codemap-search`를 빌드해 설치합니다. Cargo 기본 경로인 `~/.cargo/bin`이 `PATH`에 있어야 합니다.

        ```sh
        cargo install codemap-search
        codemap-search --version
        ```

        [crates.io 패키지 페이지](https://crates.io/crates/codemap-search)에서 게시된 버전을 확인하고 `--version`으로 원하는 버전을 지정할 수 있습니다. 해당 버전이 아직 `crates.io`에 없다면 아래처럼 로컬 소스에서 직접 빌드하세요.

        모노레포 루트에서 실행합니다:

        ```sh
        cargo install --path apps/codemap-search
        # 설치 없이 빌드만 할 때:
        cargo build --release --manifest-path apps/codemap-search/Cargo.toml
        # 기본 출력 경로: apps/codemap-search/target/release/codemap-search
        ```
    </TabItem>
    <TabItem label="Homebrew (macOS)">
        Apple Silicon과 Intel Mac용 사전 빌드 릴리스를 Homebrew 포뮬러로 설치합니다. Linux 사용자는 **Cargo** 또는 **설치 스크립트** 탭을 이용하세요.

        [공식 포뮬러 목록](https://formulae.brew.sh/formula/codemap-search)에 등록되어 있으면 아래 명령으로 설치합니다.

        ```sh
        brew install codemap-search
        ```

        `codemap-search --version`으로 설치를 확인하고 MCP 클라이언트의 `PATH`에 Homebrew 실행 경로가 포함되었는지 확인하세요. Homebrew에 원하는 릴리스가 아직 없다면 `install.sh`, `cargo install`, 또는 [GitHub Releases](https://github.com/buYoung/mcp/releases)의 macOS 압축 파일을 사용하면 됩니다.
    </TabItem>
    <TabItem label="Windows (WinGet 및 압축 파일)">
        WinGet(`com.livteam.codemap-search`) 또는 릴리스 압축 파일을 수동으로 받아 설치합니다. (`install.sh`는 macOS와 Linux 전용입니다.)

        [공식 WinGet 저장소](https://github.com/microsoft/winget-pkgs/tree/master/manifests/c/com/livteam/codemap-search)에 패키지가 올라와 있으면 다음 명령으로 설치합니다.

        ```powershell
        winget install com.livteam.codemap-search
        ```

        WinGet이 `codemap-search` 명령 별칭을 자동으로 등록합니다. 새 터미널을 열어 `codemap-search --version`을 실행하고 MCP 클라이언트가 `PATH`에서 명령을 찾을 수 있는지 확인하세요.

        WinGet에 원하는 릴리스가 아직 없거나 수동으로 설치하려면 [GitHub Releases](https://github.com/buYoung/mcp/releases)에서 아키텍처에 맞는 압축 파일과 `.sha256` 파일을 내려받아 체크섬을 확인한 뒤 `codemap-search.exe`를 꺼내 `PATH` 폴더에 넣습니다. 또는 `cargo install`로 소스에서 빌드할 수 있습니다.

        | 아키텍처 | 설치 파일 |
        |---|---|
        | x64 | `codemap-search-x86_64-pc-windows-msvc.zip` |
        | arm64 | `codemap-search-aarch64-pc-windows-msvc.zip` |

        선택한 릴리스 태그에 필요한 Windows 압축 파일이 첨부되어 있는지 [GitHub Releases](https://github.com/buYoung/mcp/releases)에서 확인하세요.
    </TabItem>
</Tabs>

## 릴리스 압축 파일 이름

선택한 릴리스 태그에 해당 아키텍처 파일이 포함되어 있는지 [GitHub Releases](https://github.com/buYoung/mcp/releases)에서 확인하세요.

| 운영체제 | 아키텍처 | 설치 파일 |
|---|---|---|
| Linux | x86_64, 기본 musl | `codemap-search-x86_64-unknown-linux-musl.tar.gz` |
| Linux | x86_64, GNU | `codemap-search-x86_64-unknown-linux-gnu.tar.gz` |
| Linux | arm64, musl | `codemap-search-aarch64-unknown-linux-musl.tar.gz` |
| macOS | Apple Silicon | `codemap-search-aarch64-apple-darwin.tar.gz` |
| macOS | Intel | `codemap-search-x86_64-apple-darwin.tar.gz` |
| Windows | x64 | `codemap-search-x86_64-pc-windows-msvc.zip` |
| Windows | arm64 | `codemap-search-aarch64-pc-windows-msvc.zip` |

Linux는 `glibc`가 필요 없는 `musl`이 기본이며, `gnu`는 x86_64 전용 옵션입니다(Linux arm64 GNU는 제공하지 않습니다).

## 문제 해결

- **명령을 찾지 못함**: 터미널뿐 아니라 MCP 클라이언트가 참조하는 `PATH`도 확인하세요(`install.sh`는 `~/.local/bin`, Cargo는 `~/.cargo/bin`, Homebrew는 Homebrew 실행 폴더, 수동 설치는 `codemap-search.exe`가 있는 폴더).
- **다운로드 오류**: 릴리스 태그, 압축 파일 이름, `.sha256` 파일, 네트워크 연결 상태를 확인하세요. 파일이 누락되면 `install.sh`는 설치를 중단합니다.
- **체크섬 불일치**: `install.sh`는 압축 해제나 디렉터리 생성 전에 즉시 중단합니다. 검증을 건너뛰지 말고 파일을 다시 받아 릴리스의 `.sha256` 값과 비교하세요.
- **쓰기 오류**: 쓰기 권한이 있는 경로를 `INSTALL_DIR`에 지정하세요(기본 경로 `$HOME/.local/bin`은 `sudo`가 필요하지 않습니다).
- **Cargo 패키지 또는 빌드 오류**: [crates.io](https://crates.io/crates/codemap-search)의 버전과 네트워크 상태를 확인하거나 로컬 소스로 빌드하세요. 컴파일이나 링크가 실패하면 Rust와 C 도구 모음을 확인하세요.
