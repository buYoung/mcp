## 설치

<Tabs>
    <TabItem label="install.sh (macOS / Linux)">
        macOS·Linux용 사전 빌드 바이너리를 내려받아 `.sha256` 체크섬을 검증한 뒤 기본 설치 경로 `~/.local/bin`에 설치합니다. POSIX 셸, `curl` 또는 `wget`, `tar`, `sha256sum` 또는 `shasum`이 필요합니다.

        ```sh
        curl -fsSL https://raw.githubusercontent.com/buYoung/mcp/main/apps/codemap-search/install.sh | sh
        ```

        다음은 설치 경로(`INSTALL_DIR`)나 버전(`--version`)을 지정하는 예시입니다.

        ```sh
        curl -fsSL https://raw.githubusercontent.com/buYoung/mcp/main/apps/codemap-search/install.sh | INSTALL_DIR=/usr/local/bin sh
        curl -fsSL https://raw.githubusercontent.com/buYoung/mcp/main/apps/codemap-search/install.sh | sh -s -- --version codemap-v0.1.6
        ```

        | 옵션 / 환경 변수 | 의미 |
        |---|---|
        | `INSTALL_DIR` | 설치 경로(기본값: `~/.local/bin`) |
        | `--version` / `CODEMAP_VERSION` | 정확한 릴리스 태그. `--version`이 우선 |
        | `CODEMAP_LINUX_LIBC` | 기본값 `musl`(정적 빌드, `glibc` 불필요). Linux x86_64에서만 `gnu` 선택 가능 |
        | `--print-target` | 다운로드 없이 플랫폼 타깃, 다운로드 URL, 설치 경로만 출력 |
    </TabItem>
    <TabItem label="install.ps1 (Windows)">
        Windows용 `.zip` 아카이브를 내려받아 `.sha256` 체크섬을 검증한 뒤 `codemap-search.exe`를 기본 설치 경로 `$HOME\.local\bin`에 설치합니다.

        ```powershell
        irm https://raw.githubusercontent.com/buYoung/mcp/main/apps/codemap-search/install.ps1 | iex
        ```

        다음은 설치 경로(`-InstallDir`)나 버전(`-Version`)을 지정하는 예시입니다.

        ```powershell
        & ([scriptblock]::Create((irm https://raw.githubusercontent.com/buYoung/mcp/main/apps/codemap-search/install.ps1))) -InstallDir "C:\Tools\bin"
        & ([scriptblock]::Create((irm https://raw.githubusercontent.com/buYoung/mcp/main/apps/codemap-search/install.ps1))) -Version codemap-v0.1.6
        ```

        | 옵션 / 환경 변수 | 의미 |
        |---|---|
        | `-InstallDir` / `INSTALL_DIR` | 설치 경로(`-InstallDir` 우선, 기본값: `$HOME\.local\bin`) |
        | `-Version` / `CODEMAP_VERSION` | 정확한 릴리스 태그(`-Version` 우선) |
        | `-PrintTarget` | 다운로드 없이 플랫폼 타깃, 다운로드 URL, 설치 경로만 출력 |
    </TabItem>
    <TabItem label="Cargo (crates.io 및 로컬 소스)">
        Rust와 C 컴파일러 도구 모음이 필요합니다.

        ```sh
        cargo install codemap-search
        ```

        [crates.io](https://crates.io/crates/codemap-search)의 특정 버전을 지정하려면 `--version`을 붙이세요.

        로컬 체크아웃에서 직접 빌드하려면 저장소 루트에서 실행하세요.

        ```sh
        cargo install --path apps/codemap-search
        # 설치 없이 빌드만 할 때(출력: apps/codemap-search/target/release/codemap-search):
        cargo build --release --manifest-path apps/codemap-search/Cargo.toml
        ```
    </TabItem>
</Tabs>

## 설치 확인과 `PATH`

`codemap-search --version`으로 실행 여부를 확인하세요.

터미널이나 MCP 클라이언트가 `codemap-search`를 찾지 못하면 아래 설치 경로가 `PATH`에 포함되었는지 확인하세요(GUI 클라이언트는 `~/.zshrc`나 `~/.bashrc`를 읽지 않을 수 있습니다).

- **`install.sh` (macOS / Linux)**: `~/.local/bin` (또는 지정한 `INSTALL_DIR`)
- **`install.ps1` (Windows)**: `$HOME\.local\bin` (또는 지정한 `INSTALL_DIR`) — 사용자 `Path`를 바꾼 뒤에는 새 터미널을 여세요.
- **`Cargo`**: `~/.cargo/bin` (Windows는 `%USERPROFILE%\.cargo\bin`)

확인이 끝나면 [MCP 클라이언트 등록](/ko/getting-started/client-setup/)으로 이동하세요.

## 릴리스 아카이브

사전 빌드 파일과 대응하는 `.sha256` 파일은 [GitHub Releases](https://github.com/buYoung/mcp/releases)에 게시됩니다.

| 운영체제 | 아키텍처 / libc | 아카이브 파일 |
|---|---|---|
| Linux | `x86_64` (`musl`) | `codemap-search-x86_64-unknown-linux-musl.tar.gz` |
| Linux | `x86_64` (`gnu`) | `codemap-search-x86_64-unknown-linux-gnu.tar.gz` |
| Linux | `arm64` (`musl`) | `codemap-search-aarch64-unknown-linux-musl.tar.gz` |
| macOS | Apple Silicon | `codemap-search-aarch64-apple-darwin.tar.gz` |
| macOS | Intel | `codemap-search-x86_64-apple-darwin.tar.gz` |
| Windows | `x86_64` | `codemap-search-x86_64-pc-windows-msvc.zip` |
| Windows | `arm64` | `codemap-search-aarch64-pc-windows-msvc.zip` |

## 문제 해결

- **다운로드 오류**: 선택한 릴리스 태그에 아카이브 파일과 `.sha256` 파일이 모두 있는지 [GitHub Releases](https://github.com/buYoung/mcp/releases)에서 확인하세요.
- **체크섬 불일치**: 검증을 건너뛰지 말고 아카이브와 `.sha256` 파일을 다시 받아 값을 비교하세요.
- **쓰기 오류**: 쓰기 권한이 있는 설치 경로를 `INSTALL_DIR` 또는 `-InstallDir`로 지정하세요.
- **Cargo 빌드 오류**: [crates.io](https://crates.io/crates/codemap-search)에서 버전 존재 여부를 확인하고 `rustc`, `cargo`, C 컴파일러 도구 모음 설치 상태를 점검하세요.
