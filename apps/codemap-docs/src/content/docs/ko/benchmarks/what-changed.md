이 벤치마크는 전달·잘림·인용 병목을 찾고 고정 조건에서 수정 전후의 변화를 확인하는 데 활용했습니다. 아래는 `codemap-search 0.14.2`에 반영된 변경 사항과 **Grafana**(`24,115`개 추적 파일, TypeScript + Go)·`gpt-6.1-sol`(`medium`)에서 관측한 결과, 그리고 남아 있는 토큰 트레이드오프입니다.

## 클라이언트 한도 부근의 압축된 순위 `search` 출력 (`e727d20c6`)

- **변경 내용**: 순위 `search` 페이지가 나열된 파일마다 일치 행 미리보기를 포함한 간결한 항목을 표시하고, 설정된 클라이언트 출력 한도 부근에서는 응답 중간을 자르는 대신 낮은 우선순위 함수 전체 본문을 정확한 `read` 범위로 대체하도록 바꿨습니다(`e727d20c6`).
- **Grafana 관측 결과**: 세 실행 환경의 `codemap-search 0.14.2` 답변 `27`건 전체에서 기본·CLI 출력 한도 도달 `0`회, 어댑터 잘림 `0`회를 기록했습니다.
- **스크립트 한도 참고**: `pi codemode`에서는 JS 스크립트 묶음 출력이 `codemode`의 기본 `10,000`토큰 상한에 닿을 때 발생하는 스크립트 잘림이 `4`회 관측되었습니다(`zvec-grep 0.2.2`는 `7`개 답변에서 `4`회, 나머지 비교 도구는 각 `9`개 답변에서 `5–11`회).

## `_meta["pi/maxOutputBytes"]` 전달 메타데이터 (`0.14.2`)

- **변경 내용**: 모든 MCP 도구가 `tools/list`에 `output.client.pi_max_bytes`(기본 `100,000`바이트)를 `_meta["pi/maxOutputBytes"]`로 알리도록 추가했습니다(`0.14.2`).
- **동작 이유**: `@buyong/pi-mcp-adapter 0.1.2`(별도 `mcp.json` 설정이 없으면 MCP 응답을 기본 `20 KiB`에서 자르는 어댑터)가 이 메타데이터를 읽어 수동 `mcp.json` 설정 없이 기본 `20 KiB`보다 먼저 `codemap-search`의 `100,000`바이트 전달 한도를 적용합니다(반면 `pi` 내장 MCP 클라이언트는 도구 메타데이터를 읽지 않고 `20 KB`에서 응답을 자릅니다).
- **Grafana 관측 결과**: `pi` 환경 `codemap-search 0.14.2` 답변 `18`건(`pi direct` `9`건 + `pi codemode` `9`건) 모두에서 어댑터 잘림 `0`회를 기록했습니다.

## 행 범위 인용 및 직접 구현 우선 지침 (`a2f81c087`, `87e36d849`, `f33203c88`, `a7c083ae6`)

- **변경 내용**: 서버 지침이 근거를 뒷받침하는 줄을 포함하는 `path:시작-끝` 행 범위로 인용하고(`a2f81c087`, `f33203c88`), 요청이 테스트나 생성 코드에 관한 것이 아니면 테스트·생성 파일을 읽거나 인용하지 않고 직접 작성된 구현을 추적·인용하도록 안내합니다(`87e36d849`, `f33203c88`, `a7c083ae6`).
- **Grafana 관측 결과**: `codemap-search 0.14.2` 답변 `27`건 중 테스트·생성 파일을 인용한 답변은 `0/27`건이었으며(`pi codemode`의 `zvec-grep 0.2.2`는 `2/7`건, 나머지 비교 셀은 `4–9/9`건), 한 줄 인용은 답변당 `1.7–2.0`건(전체 인용 중 `2.2%–2.7%`: `pi direct` `15/678`, `pi codemode` `17/632`, `Codex code mode` `18/764`)이었습니다.
- **인과 분리 미실시**: 이번 측정에서는 서버 지침만의 단독 효과와 도구 설계(색인 심볼, BM25 순위화, 내장 `read`·`grep`·`find`)의 효과를 분리해 측정하지 않았습니다.

## `gpt-6.1-sol`에서 남아 있는 트레이드오프

`Grafana`의 `gpt-6.1-sol`(`medium`) 실행에서는 세 환경 모두 `rg 15.2.0` 대비 답변당 `+1.00`~`+1.11`개의 인용 사실을 더 충족하면서도(`p = 0.0250`, `0.0300`, `0.0280`, 보정 없음) 총 토큰은 `1.54×`~`1.71×`(비캐시 토큰 `1.27×`~`1.45×`)가 들었습니다. `rg 15.2.0` 대비 GPT 토큰 오버헤드를 줄이는 문제는 미해결 트레이드오프로 남아 있습니다.
