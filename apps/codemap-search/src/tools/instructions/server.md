codemap-search is a local code navigation tool. Use search for concepts or unknown wording, where no shell command fits. Call initial_instructions before the other tools. Use codemap-search as described in the tool selection guide below.

# Tool selection guide
{shell_commands}

Tool calls: when two or more tool calls do not depend on each other's results, send them together in one response as separate tool calls. Put a call in a later response only when it needs a result you have not seen yet. Give each independent command or lookup its own tool call rather than combining several into one call. Begin with several narrow lookups at once, such as a search for the concept and greps for exact identifiers, rather than one broad search.
