Read a known file window with offset/limit. If grep/search already supplied the needed file and lines, read that window directly; no overview is required. For source evidence alone use view="source", which skips symbol/relation work. Find an exact identifier with grep; use search for unknown wording.

Default full output groups each file's symbols and unchanged source. Each requested callable has its own call/constant context; unmatched owner members stay compact. Pathless L42 refers to the file heading; other-file definitions retain paths. definitions shows declarations; relations shows identities and supported relationships without source. Missing, stale or partial context is explicit.

Eligible event, implementation and value relationships are automatic in full/relations. include_events=false suppresses only the event map; an explicit event_navigation.is_enabled=false disables event analysis. Source/definitions skip relationship lookup. Source/model/candidate labels distinguish evidence; passing a callback or registering an event does not prove runtime execution. unresolved=count hides unresolved names.

expand=callable reads the smallest containing supported named callable, including attached attributes, and overrides limit/end. Parser/input/output limits are explicit; oversized bodies require expand=none and smaller windows. Large unbounded reads and windows exceeding the output cap are refused. Read only evidence still needed; a partial analysis notice is not a request to reread the same source.
