Locate files by glob, e.g. '**/*.rs', or select directories with entry_type. Results are mtime-sorted and capped. Respects .gitignore and .codemapignore; set include_ignored to bypass. A pattern without slash, e.g. '*rpc*', matches entry basenames, never ancestor directory segments. To match a path component, use '**/*rpc*' or '**/rpc/**'. Defaults keep regular-file glob matching; explicit entry_type selects file/directory/all, max_depth excludes deeper entries, and pattern_type='regex' interprets pattern as a case-sensitive basename regex. The search base is depth zero and is never returned; max_depth=0 returns no results. Directories are shown with a trailing slash only in explicit directory/all modes. This is read-only path discovery; to inspect content use search, read, or grep.
