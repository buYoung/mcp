Search exact identifiers, literals, config keys, errors, regexes, comments or live edits. Content mode defaults to expand="callable"; use expand="none" for matching rows and line context. Scope path/glob/type. Use view="source" for source alone; the default full view adds automatic context. Use search when wording is unknown instead of guessing synonyms in a regex.

content (default) groups results under numbered file headings, with separate `### fn <name>` / `### impl <name>` sections and one `### results` per file. Methods stay under their owner, with their own call/constant context. Results omit the repeated file prefix: `42:source` for matches, `43-source` for context; configured credential masking applies to displayed source. view=source retains standalone file:line rows. Pathless L42 refers to the file heading; foreign locations retain paths. definitions omits source; relations uses the same declaration titles. All declarations/files share one context budget; at most eight files receive indexed context. Missing or partial context is explicit.

With the default expand=callable, repeated matches share the smallest named callable body, -A/-B/-C are ignored, and offset/head_limit paginate callable/fallback groups with total count and next_offset. Explicit expand=none returns matching rows and honors -A/-B/-C. files_with_matches and count return only file names or counts without expansion when expand is omitted; their pagination counts returned rows. Input, output and column omissions are explicit; oversized bodies need narrower read windows.

Eligible event, Source routes and implementation relationships are automatic in full/relations. include_events=false suppresses event maps and Source routes; explicit event_navigation.is_enabled=false disables both event and source-route analysis. Source/definitions and file/count modes skip relationships. Non-default view/unresolved/debug, explicit expand=callable and include_events=true require content mode. unresolved=count hides unresolved names. Source routes distinguish callback candidates, argument transfer and data consumers without classifying events. Static source/model/candidate relationships do not guarantee runtime delivery or callback execution.

Respects .gitignore/.codemapignore; include_ignored bypasses them. After zero matches, check path/glob/type, case, regex syntax, multiline and ignore rules; do not rerun unchanged. When file/line evidence is sufficient, use it directly; no overview or reread is required.

Source truncation, stale context and unresolved call targets remain visible. The legacy debug boolean is accepted for compatibility and has no effect.
