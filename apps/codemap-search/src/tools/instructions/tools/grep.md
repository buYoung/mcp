Use first for exact identifiers, quoted literals, config keys/defaults, exact error text, regexes, exhaustive matches, comments/non-code, or just-edited files with no index lag. It searches disk directly and avoids semantic ranking when the requested text is already known. Params mirror Claude Code Grep. output_mode: content (default) returns exact file:line locations; files_with_matches returns only the set of matching files; count returns per-file counts with no line content — use count only to size a result set, never to locate code. If a scoped pattern returns 0, do not rerun unchanged: check path, glob, type, -i, multiline, or include_ignored. Exhaustive enumeration of known names stays with grep; but when the pattern is a list of guessed synonyms or spellings for one concept, or the location is unknown, that is a search question — switch to search (scoped in a monorepo) instead of widening the regex. Partial output gives total count and next_offset; page with offset. Respects .gitignore and .codemapignore; set include_ignored to bypass.

By default returns `# codemap-search`, then numbered `## <number>. <file path>` groups, each with `### symbols` and `### results`. Each callable owns its caller/callee and constant-reference context. Directly requested declarations and their parents take priority; unmatched class/struct/impl members remain compact. Go groups methods by receiver type. A pathless `L42` location refers to the file heading; definitions in other files retain their paths. Live source text is unchanged. Missing context and budget omissions are explicit, with a narrowed read when available. File order and pagination follow the returned source page. All files share one context budget; at most eight files receive indexed context. `files_with_matches` and `count` return only their requested results.

Opt-in `view`: `source` returns live output only and skips symbol/relation work; `definitions` returns declarations only; `relations` uses a file-local `### relations` section for anchored targets and supported call/constant/implementation/value relationships; `full` preserves the default. `unresolved=count` shows totals without bounded unresolved names, including value-flow boundaries; `list` is the default. These controls do not change `search.caller_context`.

With `expand=callable`, matching stays live but -A/-B/-C are ignored. Repeated matches in one callable share one body. offset/head_limit and next_offset count unique callable or fallback groups in path/range order, not lines. Non-default controls require output_mode=content. Expanded output uses read_output_byte_cap as well as grep column limits; incomplete bodies are explicitly reported with narrowing/read guidance.

In content mode with `view=full` or `view=relations`, eligible event endpoints and supporting definitions overlapping the returned source lines automatically add a separate bounded static event map. Unrelated code, strings and comments produce no event section or empty-event notice. Set `include_events: false` to omit the map. Source/definitions skip event lookup; file/count modes retain their existing output and reject an explicit `include_events: true`. Event analysis is enabled by default; explicit `[event_navigation].is_enabled=false` disables it. Bus/key/handler locations and uncertainty are distinct from direct calls; never infer runtime delivery from this map.

Returned lines can also anchor bounded source value summaries, independently of event rules: argument/parameter, return/binding, captured values, object fields and callback-use candidates. `[source]`, `[model]` and `[candidate]` keep evidence distinct; passing a function does not prove execution. Source/definitions and file/count modes skip this work. Excluded or changed dependencies are withheld with bounded diagnostics.

Repeated value-analysis diagnostics are deduplicated across files. A shared work-limit notice appears once; later value analysis stops when that limit is exhausted. Symbol-context `Next: read` hints are limited to three unseen declaration locations per response. Already displayed source, unresolved analysis and missing declarations do not trigger automatic reread prompts.
