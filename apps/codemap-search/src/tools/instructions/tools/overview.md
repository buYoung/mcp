Inspect folder contents and directory structure to understand a repository area. Use a folder path for orientation. If grep/search already supplied the needed file and line, use read directly. Known identifiers belong in grep; unknown wording belongs in search. A root overview is not a prerequisite for those lookups.

No path returns a bounded root map with recursive directory counts and the first files by path; format="llms-txt" selects a bounded text map. A folder lists significant file/symbol names without ranges. A file lists significant indexed declarations with exact ranges; unexported function-local declarations may be omitted. Missing symbols here do not prove the source is absent.
