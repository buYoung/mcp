Inspect folder contents and directory structure to understand a repository area. Use a folder path for orientation. If grep/search already supplied the needed file and line, use read directly. Known identifiers belong in grep; unknown wording belongs in search. A root overview is not a prerequisite for those lookups.

No path returns a bounded root map with recursive directory counts and the first files by path; format="llms-txt" selects a bounded text map. A folder lists significant declarations with source-backed signatures and nested fields/methods, without line ranges. A file lists significant indexed declarations with exact ranges; unexported function-local declarations may be omitted. Missing symbols here do not prove the source is absent.

Root and monorepo workspace-root overviews include indexed-file language statistics by default; set `[tool_output].is_overview_stats_enabled = false` to omit them. The counts cover only the physical files already present in that indexed root scope, use tokei with total = code + comments + blanks, fold embedded language blobs once into the physical file's language bucket, and report unavailable files. Other folders and files omit statistics. Pending collection is explicit; retry overview to reuse completed counts.
