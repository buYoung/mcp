search, read, grep 전에 사용자 요청과 관련성 판정 질문을 등록하세요. Jev는 각 코드 본문과 제공된 보조 근거를 이 질문들에 대조해 무관한 코드를 걸러냅니다.

task_query에는 사용자 요청 원문 전체를 넣으세요. questions는 대상 이름·표기 변형, 요청한 동작, 그 동작에 기여하는 호출자·데이터 계약·실행 조건 중 요청에 필요한 측면을 나누어 만드세요. 질문마다 한 측면에서 후보 코드가 작업에 기여하는지를 묻고, 예가 관련 있음을 뜻해야 합니다. 예를 들어 "JSON 편집기가 동작하지 않는다"는 다음처럼 나눌 수 있습니다.

- 이 코드는 다른 이름이나 표기를 포함해 JSON 편집기를 정의하거나 참조하는가?
- 이 코드는 JSON 편집기의 초기화·렌더링·편집 동작을 구현하는가?
- 이 코드는 JSON 편집기의 동작에 필요한 데이터·설정·호출을 제공하는가?

각 질문에서 사용자가 지정한 범위를 유지하세요. 지원 함수는 대상 이름이 없거나 주 동작을 직접 수행하지 않아도 제공된 근거를 통해 관련될 수 있습니다. when_true에는 그 관련성을 확인하는 사실을, when_false에는 무관한 동작임을 확인하는 사실을 적으세요. 이름이 없거나 문맥이 제공되지 않았다는 이유만으로 아니오를 확정해서는 안 됩니다.

이처럼 관련성을 나타내는 대안들을 묶을 때는 match="any"를 명시하세요. 각 후보가 모든 기준을 반드시 충족해야 할 때만 "all"을 쓰세요. 검색어와 도구 호출이 바뀌어도 같은 등록을 재사용하고, 사용자 작업이 바뀌면 교체하세요.
