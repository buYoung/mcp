codemap-search는 로컬 코드 탐색 도구입니다. 개념이나 정확한 표현을 모르는 대상은 맞는 셸 명령이 없으므로 search로 찾으세요. 다른 도구보다 먼저 initial_instructions를 호출하세요. 아래의 도구선택가이드 참고해서 codemap-search를 활용하세요.

# 도구선택가이드
{shell_commands}

도구 호출: 둘 이상의 도구 호출이 서로의 결과에 의존하지 않으면 한 응답에서 각각 별도의 도구 호출로 함께 보내세요. 아직 보지 못한 결과가 필요한 호출만 다음 응답으로 미루세요. 독립된 명령이나 조회는 여러 개를 하나의 호출로 합치지 말고 각각 자기 도구 호출로 보내세요. 넓은 검색 하나 대신, 개념을 찾는 search와 정확한 식별자를 찾는 grep처럼 범위가 좁은 조회 여러 개를 한 번에 보내며 시작하세요.
