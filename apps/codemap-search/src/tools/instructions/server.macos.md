codemap-search tools to use instead of macOS shell commands:
- codemap-search_grep: rg, grep, ag, git grep
- codemap-search_read: cat, less, head, tail, sed -n
- codemap-search_find: find, fd, mdfind, ls, tree, rg --files. For immediate directory entries, use pattern="*", entry_type="all", max_depth=1.
