# 과거 다중 저장소 A 정식 벤치마크 고정 결과 — formal-r1

**적용 범위 정정:** 사용자가 채택한 앞으로의 정식 벤치 대상은 Grafana만이다. 이 문서는 Grafana가 포함되지 않은 과거 6개 저장소 결과이며, Grafana 정식 A 기준값으로 사용하지 않는다. 원래 60회 결과·보류·해시는 그대로 보존한다.

**A의 정식 평가 30문제 × 2회, 총 60회 결과를 고정 보존한다.** 정답 확정 54회·부분 정답 1회·오답 3회·판정 보류 2회, 평균 전체 토큰은 **85,425.03**이다. 이 표는 2026-09-08 실행의 원래 결과이며 새 측정·재채점은 없다.

참조 ID는 **`formal-r1-A`**다. 이후 비교표에서는 **“A — formal-r1, 설명 보완 전 과거 실행”**으로 표시하고 수치·분모·보류를 유지한다. 사용자의 유지 요청에 따라 후보나 현재 제품이 바뀌어도 이 기록을 자동 재측정·재채점하거나 새 결과로 덮어쓰지 않는다.

## 고정 조건과 비교 한계

- 고정 시각: `2026-09-08T08:39:51.681837+09:00`. 실행 모델 `gpt-5.6-luna` medium, Codex CLI `0.153.4`; 당시 채점 모델은 `gpt-6-astra` low다.
- A 도구: `rg`, `grep`, `find`, `read`. 실제 선언은 [원값 JSON](A.json)의 `actual_A_tools`에 보존했다. 현재 승인된 A 도구 설명으로 바꾸어 적지 않는다.
- 각 실행의 한도는 300초·탐색 80회·전체 500,000토큰이다. 고정 데이터·프롬프트·하네스 해시·각 저장소 커밋은 JSON에 보존한다. 원래 A/B 정식 전체는 120회지만 **이 표의 A 분모는 60회**이며 다른 집단·준비 실행·채점 비용을 섞지 않는다.
- 당시 빈 경로·1부터 시작하는 read 행 번호 안내 부족으로 **95건의 계약 관련 오류**가 발생했다(빈 경로 84건, 읽기 시작값 11건). A의 **44/60회 실행·26/30문제**에 영향을 줬으며 전체 도구 오류는 98건이었다. 이 비용을 사후 차감하거나 정상화한 “보정 A”를 만들지 않는다.
- `fmt-04-A-1`, `fmt-04-A-2`는 원래 채점 입력에 대체 인용 원문이 없어 보류됐다. 이후 원문 확인을 이유로 원래 점수를 바꾸지 않는다. Java/C++ grep 근거 노출 분석의 한계도 보존한다.
- **이 기록을 계속 유지하는 것과 현재 제품 개선의 공정한 대조군으로 사용할 수 있는지는 별개다.** 설명 보완 후 A, 다른 문항·프롬프트·채점 계약 또는 실행 시점의 결과와 자동으로 동일시하지 않는다. 알려진 평가 오류가 있으므로 이 표만으로 현재 제품의 개선을 확증하지 않는다. 현재 A 도구 계약은 기존 [보고 기준](../../REPORTING.md)과 별도로 식별한다.
