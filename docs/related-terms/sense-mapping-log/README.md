- 3단계: 평가 세트 적중이 80.8%에서 84.8%로, 3단계 대상 집단(`target`)은 85.8%에서 93.8%로 올랐다. 잃은 적중은 없다.
- 4단계: 매핑한 단어 934개, 무작위 표본 3,000개, 매핑한 주제에 속한 다른 단어 62,865개에서 뜻이나 관련어를 잃은 단어는 없다. 첫 뜻이 바뀐 단어는 4개다.
- 5단계에서 word-eval 스크립트가 `rt-sense/4`도 읽도록 고치고 기본 데이터셋을 `rts4-86c5620af1f181ce`로 바꿨다.
- 6·7단계: 평가 세트 적중이 84.8%에서 85.3%로, 주 분야 적중이 75.9%에서 78.1%로, 첫 뜻 적중이 64.3%에서 67.9%로 올랐다. 적중을 잃은 단어는 3개다(주 분야 판정의 결과). 뜻이나 관련어를 잃은 단어는 모두 잘못 들어간 단어를 옮긴 데서 나왔다. 첫 뜻이 바뀐 2,484단어 중 2,113단어는 가중치가 같은 뜻을 분야 이름순으로 놓는 규칙 때문이다.
- 8단계: 기본 데이터셋을 `rts4-e5083ab344e1336d`로 바꿨다. 가중치가 같은 뜻을 주제의 단어 수가 많은 순으로 놓도록 고쳐, 재분류로 첫 뜻이 바뀐 단어가 2,484개에서 510개로 줄었다. 첫 뜻 적중은 68.8%다.
- 9단계: 뜻을 질의와의 임베딩 유사도 순으로 정렬한다. 첫 뜻 적중은 69.6%다. 생성 횟수를 무시하는 것을 비롯한 결함 9가지를 [09-similarity-order.md](09-similarity-order.md) 5절에 적었다.
- 10단계: 생성 횟수 순을 지키고 생성 횟수가 같은 뜻만 질의 유사도로 정렬하는 규칙 A를 기본값으로 했다. 첫 뜻 적중은 70.5%, 맞는 뜻의 평균 순위는 1.36이다. 독립 분석 두 번과 블라인드 판정에서 다른 규칙이 A보다 낫다는 근거는 나오지 않았다.
- 11단계: 관련어가 하나도 없는 뜻이 텍스트 출력에서 빠지던 문제를 고쳤다(표본 3,237단어 중 2단어 → 0). `revise_topics.py`에 관련어를 다른 뜻으로 옮기거나 뜻에서 떼어내는 연산과, 검토로 만든 입력 연결을 끊는 연산을 더했다. 데이터셋은 그대로다.
- 12단계: Claude Sonnet 5.5가 알려진 결함 9단어, 사전 전체에서 고른 1,441단어, 여러 단어 표현 1,000개의 뜻을 판정해 틀린 뜻 1,012개를 찾았다. 관련어를 맞는 뜻으로 옮기거나 떼어내 고쳤고, 흔한 단어 206개에 빠진 뜻 233개를 연결했다. 평가 세트 적중은 86.2%, 주 분야 적중은 79.0%, 첫 뜻 적중은 71.0%로 올랐고 잃은 적중은 없다. K1·K3~K5와 K6의 `specs`가 고쳐졌다. 기본값을 `rts4-710c8ba0d79a776a`로 바꿨다.
- 13단계: 조회가 rtr1에서 읽는 것은 입력 해석, 굴절형 근거, 단어 벡터다. 사전 단어만 남긴 부분집합(259MiB)으로 3,253단어 응답이 원본과 모두 같았다. 벡터를 빼면 41MiB이고, 이때는 유사도 정렬을 끄게 되어 표본 3,000단어 중 285단어의 첫 뜻이 달라진다. 구현은 하지 않았다.
- 14단계: 12단계에서 틀렸다고 판정한 뜻 1,012개를 Claude Sonnet 5.5가 다시 판정해, 두 판정이 일치한 997개만 고쳤다. 남은 여러 단어 표현 1,048개를 판정해 두 판정이 모두 틀렸다고 한 706개를 더 고쳤다. 평가 세트 점수는 12단계 판과 같다(적중 86.2%, 첫 뜻 적중 71.0%). 기본값을 `rts4-301d57d419380d08`로 바꿨다.
- 15단계: 기호가 붙은 입력이 다른 단어의 기본형으로 읽히는 원인은 `category_lookup.same_word`가 같은 철자 단어는 버리고 기본형은 받는 비대칭이다. 가장 좁은 규칙 변경도 사전 전체에서 좋아지는 단어와 나빠지는 단어가 비슷해(132 대 115) 코드는 바꾸지 않았다.
- 16단계: sqlite 파일을 분석해, 조회가 읽지 않는 인덱스 두 개와 테이블 하나를 빼고 관련어의 종류를 번호로, 표기를 키와 다를 때만 저장하는 `rt-sense/5`를 만들었다. 크기는 34.8% 줄었고 사전 전체 176,351단어의 조회 결과와 적재 시간은 그대로다. 수정 도구는 두 판을 모두 받는다. 기본값을 `rts5-75e02862daa29308`로 바꿨다.

## 정한 기준

- 단어의 설명에 그 분야의 대상이 들어 있으면 그 분야에 연결한다. 다른 분야가 더 주된 분야라는 것은 빼는 이유가 아니다.
- 매핑은 분야가 아니라 주제에 건다. 나중에 주제를 다른 분야로 옮기면 단어가 따라간다.
- 구조 정리(2단계)는 조회 결과를 바꾸지 않는다. 결과가 바뀌는 것은 매핑 확장(3단계)부터다.
- 주제의 주 분야는 그 주제의 대상이 속한 분야로 정한다. 대상이 같은 주제는 합치고, 새 주제는 단어 두 개 이상을 담을 때만 만든다(6단계).
